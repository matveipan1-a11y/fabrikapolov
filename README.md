# FabrikaPolov

Мобильное PWA с онлайн-приёмом заказов. Каталог, корзина и избранное доступны офлайн. Отправка заказа требует интернет; заказ считается оформленным только после ответа сервера.

## Запуск сервера

Нужен Node.js 24 или новее. Задайте переменные окружения:

| Переменная | Назначение |
| --- | --- |
| `ADMIN_TOKEN` | Обязательный секрет администратора от 24 символов |
| `PORT` | Порт HTTP, по умолчанию `3000` |
| `DATA_DIR` | Каталог для заказов; по умолчанию `./data` |
| `CONTACT_PHONE` | Настоящий телефон фабрики, показывается клиентам |
| `CONTACT_EMAIL` | Настоящая почта фабрики, показывается клиентам |
| `ORDER_WEBHOOK_URL` | Необязательный HTTPS-адрес для уведомлений о новых заказах |
| `ORDER_WEBHOOK_SECRET` | Необязательный Bearer-токен для webhook |

Пример для PowerShell:

```powershell
$env:ADMIN_TOKEN = 'замените-на-случайный-секрет-длиной-от-24-символов'
$env:CONTACT_PHONE = '+7 999 123-45-67'
$env:CONTACT_EMAIL = 'orders@example.com'
node server.js
```

Сервер принимает `POST /api/orders`, пересчитывает цены и скидку, проверяет данные и записывает заказ в `DATA_DIR/orders.jsonl`. После записи может отправить JSON заказа на webhook. Заказы доступны оператору на `/admin.html` после ввода `ADMIN_TOKEN` или через `GET /api/orders` с заголовком `Authorization: Bearer <ADMIN_TOKEN>`. Проверка работы: `GET /api/health`.

Для использования клиентами разместите сервер за HTTPS-прокси, укажите реальные контакты, настройте постоянное хранилище для `DATA_DIR`, резервное копирование и обработку новых заказов через webhook либо защищённый API. Не публикуйте `ADMIN_TOKEN` и каталог данных. Встроенный HTTP-сервер не завершает TLS сам.

## Docker

Соберите образ: `docker build -t fabrikapolov .`. Запускайте с переменными выше, томом `/data` для заказов и HTTPS-прокси перед портом 3000. Контейнер работает без прав root.

## Установка на телефон

- **Android / Chrome:** откройте HTTPS-адрес приложения → меню → **Установить приложение**.
- **iPhone / Safari:** откройте HTTPS-адрес → **Поделиться** → **На экран «Домой»** → **Добавить**.

После первого открытия интерфейс доступен офлайн. Заказ отправляется только при подключении к интернету. Промокод `POL10` даёт скидку 10%. Онлайн-оплата не предусмотрена: итоговая сумма заказа подтверждается менеджером.
